# Pasta Atelier — Full Stack PHP Portfolio Project

An original restaurant website concept built from scratch for a portfolio.

## Stack
- HTML5
- CSS3 (separate stylesheet per page)
- Vanilla JavaScript
- PHP
- Local PHP menu data (no database required)

## Features
- Responsive multi-page restaurant website
- Menu displayed from local PHP data
- Menu category filtering with JavaScript
- Original visual identity using an olive / warm paper / muted rust palette

## Run with XAMPP
1. Copy `makronato` into `C:/xampp/htdocs/`.
2. Start Apache.
3. Open `http://localhost/makronato/`.

## Notes
The menu is stored in `data/menu.php`, so no MySQL database is required. The address, phone number and email are demo content and should be replaced with real restaurant information if the project is used for a client.
